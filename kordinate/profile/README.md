# Profile

Runtime configuration — cluster definitions, service endpoints, kustomize overlays, and authentication locks.

## Contents

| Path | Purpose |
|------|---------|
| `config.yaml` | Cluster IPs, domains, service endpoints, Cloudflare config — source of truth |
| `.mcp.json` | MCP server list (playwright, beorn) |
| `keybindings.json` | Tmux keybindings |
| [locks/](locks/) | Per-agent lock files used by guards for authentication |
| [overlays/](overlays/) | Kustomize overlays per cluster — generated by `/infra generate-overlays` |
| [shared/](shared/) | Shared profile resources |

## Overlays

Cluster-specific kustomize patches organized by namespace:

```
overlays/vandc/
├── gateway/    # Gateway namespace — ingress, Alloy, Loki federation
├── master/     # Master namespace — workstation, Beorn
└── monitor/    # Monitor namespace — Grafana, dashboards
```
