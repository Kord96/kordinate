# Concept References

This directory is the canonical Augur catalog entrypoint for concepts.

Concept references are organized by semantic family:
- `design-patterns/`
- `anti-patterns/`
- `domain-models/`
- `flow-shapes/`
- `structure-shapes/`

Each concept reference is a Markdown file with frontmatter. The frontmatter
carries the machine-readable `signatures` used by detector and skill tooling,
while the body contains the human-readable explanation.
