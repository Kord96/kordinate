# Benchmark Scripts

These scripts support Augur evaluation work rather than live `/analyze` runtime orchestration.

- `run_ablation_codex.py`
  - execute ablation manifests against Codex
- `run_pilot_slice.py`
  - execute smaller benchmark slices
- `evaluate_fact_extraction.py` and `evaluate_framework_detection.py`
  - score deterministic layers
- reflection collectors and aggregators
  - gather and summarize benchmark reflections
