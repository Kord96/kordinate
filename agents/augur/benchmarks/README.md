# Augur Benchmarks

This tree contains evaluation assets that should not live in the runtime skill or workflow script surfaces.

- `analyze/`
  - benchmark datasets, ablation manifests, scoring references, and retained run corpora for `/analyze`
- `scripts/`
  - runners and aggregation helpers for ablations, pilot slices, and reflection collection

Live audit prompts and runtime verification docs remain under `skills/analyze/audit/`.
