# Augur Memory

This directory is Augur's semantic memory source.

Use it in three layers:

- `workflow.md` for the core analyze/design workflow
- `tools.md` for tooling and validation expectations
- `indexes/` and `contracts/` for stable preloadable ontology and normative contracts

Large semantic catalogs are on-demand:

- `catalog/concepts/`
- `catalog/frameworks/`

Start from each catalog's README or index entrypoint before opening individual concept or framework files.
