# Augur Concepts

This directory is the canonical Augur semantic library.

Concept references are organized by family:
- `design-patterns/`
- `anti-patterns/`
- `domain-models/`
- `flow-shapes/`
- `structure-shapes/`
- `frameworks/`

Each concept reference is a Markdown file with frontmatter. The frontmatter carries machine-readable signatures and review metadata, while the body contains the human-readable explanation.
