# Bundle Mode: Holistic

Use this guidance when the prepared bundle mode is `holistic`.

Holistic mode means the full concept bundle is already resident in context.

## Expectations

- Use the resident concept bundle from the start as an interpretation layer for architecture, patterns, tensions, and nearby concept distinctions.
- Let rich concept knowledge deepen your understanding of the system early, especially when reading runtime wiring, boundaries, and flow-defining code.
- Still ground the analysis primarily in the prepared facts and the repo's actual runtime shape.
- Use `facts/concept-evidence.json` and any attached semantic questions early when they materially improve architectural interpretation.
- Do not let detector-suggested concepts replace direct grounding from entrypoints, registrations, state boundaries, and cross-component interactions.
- Do not let rich concept labels override direct evidence about dependency direction or configurable state semantics.

## Goal

Produce concept-rich architectural synthesis without turning the run into a detector-led concept hunt.
